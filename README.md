# Open Social Scheduler

An open-source social media scheduling platform for planning, managing, and automating social media posts.

## Features

- Create social media posts
- Schedule posts
- Manage scheduled content
- Track publishing status
- Retry failed publishing jobs
- Multi-platform support planned
